Floxac — تطبيق شبكة اجتماعية كامل يعمل بدون خادم
التشغيل: افتح index.html مباشرة، أو ارفع المجلد كله إلى GitHub Pages / Netlify / Cloudflare Pages لتثبيته كتطبيق (PWA).
المميزات: حسابات حقيقية (تسجيل/دخول)، منشورات بصور وفيديو، قصص 24 ساعة، ريلز، إعجابات، تعليقات، إعادة نشر، حفظ، متابعة، رسائل خاصة، إشعارات، بحث ووسوم، عربي/إنجليزي، فاتح/داكن، نسخ احتياطي واستيراد.
ملاحظة: البيانات محفوظة على نفس الجهاز والمتصفح (IndexedDB). المشاركة الحقيقية بين أجهزة مختلفة تحتاج خادمًا (Backend).
